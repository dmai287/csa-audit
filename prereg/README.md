# Pre-registration

The statistical analysis plan (paper Section 4.8) and the thresholds in
`configs/thresholds.yaml` are deposited on OSF as a time-stamped
pre-registration **before any reconstruction is run**. Place the deposited PDF
here as `prereg_v1.pdf` together with `prereg_v1.sha256`, and record the OSF
identifier below. Any later deviation is logged in `CHANGELOG.md`.
